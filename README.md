# 🛼 Skate Tracker

A web app for tracking roller skating skills, practice sessions, and progress.

## Why I Built This

I'm learning web development by building a tool I can actually use for my roller skating practice.

## Current Features

- Add skating skills
- Edit existing skills
- Delete skills
- Track skill level
- Track skill status
- Track confidence
- Save skill data in local storage

## Built With

- HTML
- CSS
- JavaScript

## What I'm Learning

- Semantic HTML
- CSS Grid and Flexbox
- DOM manipulation
- JavaScript events
- Arrays and objects
- CRUD operations
- Local storage
- Git and GitHub
